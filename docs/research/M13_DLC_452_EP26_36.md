# M13 DLC CE452 EP26–EP36 门诊断与全链复现

> 任务：task-14（M13 P0-B 续）：CE452 自然推进只到 EP25/var619=25，定位 EP26 起被挡的确切原因，并证明 EP26–EP36 可全链跑到 var619=36。

## 0. 结论速览

- **EP26 不是脚本层数据门（不是 self11 之类的剧情条件门）。** 它是 EP26 内嵌战斗（210 CommonEvent 500239 @pc4184）在“累积存档式”单局运行里被判成**失败**，输掉后走 負け 分支触发全灭 game-over，事件链在 @pc6087 的 self10 += 1 之前就被整条拆掉，所以 var619 永久卡 26。
- **唯一决定性变量 = 全局 var395（magic 2000395）。** EP17「画竜点睛」在 dump idx 2362 把 var395 置 2（由衣强化剧情），**全工程没有任何事件把它写回 0**。战斗侧事件 243/244 以 var395==2 判定，故一个陈旧的 2 让 EP26–EP36 的内嵌战斗全部判负。
- **修复/夹具证据：** 每个 EP 前把 var395 清 0，同一局自然链即可从 EP0 一路跑到 **EP36，var619=36**（见 §4 表）。
- **这类“陈旧战斗标志导致战斗误判”属于战斗/引擎侧生产问题（疑似移植缺口：原版引擎应在战斗结束原生重置 var395，或全灭判定不应清整条事件链）。不改本任务范围；已上报 Lead 决策。**

## 3. 现象与门定位

- **自然链（真实累积、无夹具）**：`start_event_resuming(452)` 反复零参调用，var619 0→25（EP0..EP25 全部完成，self10=ep+1 持久化，得益于 M13 common-self 持久化修复）。到 EP26：先 @pc2 写 var619=26，随后内嵌战斗判负（self11=-1），負け分支（@pc4189..4226）经 helper 500226@pc4223 触发全灭 game-over → 整局事件实例被清空（instances==0）→ 未执行 @pc6087 的 self10+=1 → **self10 卡 26，之后每次调用都重放 EP26**。
- **门结构（来自 wolf-vm Program.blocks，非 dump——dump 缺 498/499 结束标记）**：
  - blk#87 @3835 Condition（EP 分派 self10 24–27）：case1→3837(EP24)、case2→4026(EP25)、case3→4164(EP26)、case4→4512(EP27)，else 无，end_pc=4592 end_target=4593。EP26 体 = 4164..4510，case4 标记在 @4511。
  - blk#93 @4185 Condition `self11 >= 1`：case1→4187（TRUE，self11>=1，跳过負け场景）；else_pc=4189（FALSE，self11<1，播負け/受伤惩罚场景 4189..4226）；end_pc=4226 end_target=4227。两分支都汇到 4227 的胜利场景（温泉 H、由衣），再经 @4511 标记回到 blk#87 end_target 4593，继续后续分派器，最终 @6087 self10+=1。
  - blk#94 @4197 Condition（self30>=4）：嵌套在負け分支内，case1→4199，end_pc=4204 end_target=4205。
- **self11 的写入方式**：@pc4184 `210 CommonEvent intArgs=[500239, 16777220, 75, 0, 0, 0, 1600011]`。param_status 0x01000004 = bit24(返回值调用) + 低半字节 4 个数值参数；尾随 1600011 = self11 magic，是战斗返回值的落地槽。所以 452 里没有任何 SetVariable dest=1600011，self11 完全由 210 返回值机制写入。
- **@pc4185** `111 intArgs=[17, 1600011, 1, 1]` = `(self11 >= 1)`。

## 4. 根因：全局 var395 泄漏

- 全工程扫描（work/wolftl + wolftl2 dump/common 全部事件）中，magic **2000395** 的**唯一写入者**：
  - 452_■DLCストーリー idx 2362 `SetVariable [2000395, 2, 0, 0]`（EP17 画竜点睛，由衣强化剧情）。
  - 301_ランダムイベント idx 2240（也写 =2）。
  - **没有任何事件把 var395 写回 0。**
- var395 的读取点：234_ステータス表示 idx210（var395>=2）、243_┣敵の行動 idx905（var395==2）、244_┗終了判定 idx88（var395==2）、301 idx2151、510 idx721、513 idx722。⇒ var395==2 是战斗/状态“模式标志”，陈旧 2 让 EP26–EP36 内嵌战斗判负。
- **对照实验（默认测试 dlc452_ep26_stale_var395_is_the_blocker，受控 before/after 全新局）**：
  - var395=0 + seed self10=26 → EP26 **胜**（self11=1，maxpc=4510，self10→27）。
  - var395=2 + seed self10=26 → EP26 **负**（self11=-1，maxpc=4224≤4226，self10 卡 26）。
- **二分观察**：var395 只在 EP17（idx2362）变成 2。EP18–EP25 不跑真实战斗所以正常完成；EP26–EP36 全跑战斗 500239，故在 var395==2 时全负。
