# M13 DLC CE452 EP26–EP36 门诊断与全链复现

> 任务：task-18（承接 task-14）：给 var395「引擎侧修复」下最终结论，并证明 CE452 自然推进 EP0→EP36（var619=36）无需任何 var395=0 夹具。
> 结论：**不是移植缺口，不改生产代码。** var395 是永久技能解锁标志（不能重置）；EP26 卡住是探针缺「已升级队伍」战斗属性造成的假象。用一次性预置真实战斗属性（代表已升级队伍）即可让同一局自然链 EP0→EP36 全程通过。

## 0. 结论速览

- **EP26 不是脚本层数据门**（不是 self11 之类的剧情条件门），也**不是移植 bug**。EP26 @pc4165 内嵌战斗（210 CommonEvent 500239 @pc4184）的胜负由「我方战力 vs 敌方槽」决定；这条剧情战敌方槽是**固定高值 ~4500**，因此需要**正常升级后的队伍**才能赢。
- **var395（magic 2000395）是「由衣习得献身（self-sacrifice）」的永久技能解锁标志**，不是战斗临时变量：
  - 全工程唯一写入：452_■DLCストーリー idx2362 `SetVariable[2000395,2]`（EP16→EP17 之间的由衣强化剧情，2359「由衣学会了技能献身！」）与 301_ランダムイベント idx2240；**都是写 =2，没有任何事件写回 0**。
  - 读取点：状态页 234 idx210（显示技能图标）、相册 510/513、战斗分支 243 idx905 / 244 idx88（var395==2 → 战斗中追加「献身」技能）。
  - ⇒ **引擎层若在战斗结束把 var395 重置 0，会永久抹掉由衣的「献身」技能**（状态/相册图标消失、452 idx2306 学习剧情门反转）。**明确否决「引擎重置 var395」方案。**
- **EP26 判负的真因 = 探针没有真实的战斗属性。** 隔离探针直接 start_event(452)、从未跑升级/属性读取（CE230 等），我方战力只有 seed_battle_databases 的默认 ~15，远低于固定敌槽 4500 → 必败。**一次性预置 var 2000040..45 与 2000170..175（代表已升级队伍）后，同一场战斗在 var395=2 时也判胜**（见 §4）。
- **全链证据（无 var395 夹具）：** 一局内 seed 一次「已升级队伍」属性、var395 全程不清洗，自然链 EP0→EP36 全通，**var619=36**；var395 到 EP16 自然变 2 并**一直保持 2 到 EP36**（见 §6 表）。这直接证明 var395 不需要、也不能被清。

## 3. 现象与门定位

- **自然链（真实累积、无夹具、默认属性）**：`start_event_resuming(452)` 反复零参调用，var619 0→25（EP0..EP25 全部完成，self10=ep+1 持久化，得益于 M13 common-self 持久化修复）。到 EP26：先 @pc2 写 var619=26，随后内嵌战斗判负（self11=-1），負け分支（@pc4189..4226）经 helper 500226@pc4223 触发全灭 game-over → 整局事件实例被清空（instances==0）→ 未执行 @pc6087 的 self10+=1 → **self10 卡 26，之后每次调用都重放 EP26**。**注意：此「卡住」是默认属性下必败导致，不是门。**
- **门结构（来自 wolf-vm Program.blocks，非 dump——dump 缺 498/499 结束标记）**：
  - blk#87 @3835 Condition（EP 分派 self10 24–27）：case1→3837(EP24)、case2→4026(EP25)、case3→4164(EP26)、case4→4512(EP27)，else 无，end_pc=4592 end_target=4593。EP26 体 = 4164..4510，case4 标记在 @4511。
  - blk#93 @4185 Condition `self11 >= 1`：case1→4187（TRUE，self11>=1，跳过負け场景）；else_pc=4189（FALSE，self11<1，播負け/受伤惩罚场景 4189..4226）；end_pc=4226 end_target=4227。两分支都汇到 4227 的胜利场景（温泉 H、由衣），再经 @4511 回到 blk#87 end_target 4593，继续后续分派器，最终 @6087 self10+=1。

### 4.2 决定性属性对照实验（fresh Game + start_event(452) + self10=26 + var395=2）
- **空属性**（默认 seed_battle_databases，强度 ~15，type0 row12 col25=15）→ 我方战力上限 maxP28=15 vs 敌 4500 → **LOSE**（self11=-1，var619=26，maxpc=4224）。

- 结论：**同样的 var395=2，空属性必败、已升级队伍必胜。** 卡点是我方战力数值，不是 var395。

### 4.3 var395 语义（永久技能解锁标志，绝不能重置）
- 写者（全 dump 仅 2 处，均 =2）：452 idx2362、301 idx2240；无任何回写 0。
