## 1. 方法（EventRunner 驱动）

统一用 `wolf_game::Game` 无头驱动：

1. `Game::new(data_root())` → `vm.clear_common_self()` → `auto_advance=true`、`auto_choice=false`；
2. `vm.vars.set(id, value)` 注入状态（变量 id 为真实编号，非脚本里的 2000000+ 偏移）；
3. `start_event(id)` 直接进事件；
4. 循环 `key_bits = OK/0` + `frame()`；菜单 `game.choices` 出现则 `game.reply(ChoiceReply::Index(i))`；自绘图形菜单则等目标文字 picture 出现后 `mouse=[x,y]→按钮按下/抬起` 点击；
5. 断台词：`game.messages.last().text`；断状态：`game.vm.vars.get(id)`；断无告警：`game.stats.warnings==0`。

门语义沿用 OPCODE_SPEC §5.9 / program.rs:561：单条 op111 的多个三元组是「首真命中的有序分档」，不是逻辑与；只有层层嵌套的单条件 111（如 CE310@159→161→163→165）才等价于 AND。详见 M13_H_THRESHOLDS.md §1。
