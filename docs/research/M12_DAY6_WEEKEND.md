## 4. 体力与随机性

自主锻炼/悠然自得的体力变化受零售 PRNG 与输入时序影响：

- 本测试路径（`frames=11247`）实测 `60 → 40 → 40 → 60`；
- 早期探针多喂了若干帧，同一活动得到 `60 → 45 → 55 → 60`。

因此测试只断言“自主锻炼会消耗体力”（`after_training < start`），并记录后两段的值；不把体力数值写死。日程时间与菜单内容是稳定的。
