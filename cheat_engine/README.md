## 地址原理（为什么只需改偏移）

原版 Wolf RPG 运行时把 800 个「通常变量」（`通常変数`，脚本地址 2000000+n）连续存放在一块 `int[800]` 数组里。其定位链为：

```
正常变量 n 的值地址 = [[ [Game.exe+0xDAD67C] + 0 ]] + n*4
```

- `Game.exe+0xDAD67C` 处存放的是变量容器的外层指针；
- CE 里用「基址 `"Game.exe"+00DAD67C` + 两级偏移 `[fieldOffset, 0]`」即可解析到 `数组首地址 + fieldOffset`；
- 因此 **`fieldOffset = var_id × 4`**。例如金钱 = var7 → 0x1C；技能点 = var10 → 0x28；信赖 = var21 → 0x54。

所有条目变量类型为 `4 Bytes`、`ShowAsSigned=0`（与原表一致；数值均为非负整数）。

## 使用方法

1. 打开游戏并进入存档（数值已加载到内存）。
2. 打开 Cheat Engine，`File → Open` 选择 `妹相随 全能修改表 v4.CT`，或在进程列表中附加到 `Game.exe`。
3. 在表里展开分组，勾选某条目左侧方框可**冻结**该值；双击「Value」列可直接改成想要的数值。
4. 常用改法示例：
   - **改钱**：哥哥·战斗与属性 → 金钱，改成 999999。
   - **改属性/技能点**：攻击技术/智慧/技术/防御技术/毅力、技能点。
   - **改好感**：妹妹·关系与状态 → 信赖 / 性趣味 / 心情 / 妹妹性欲(发情度)。
   - **解锁技能**：技能·战斗力 / 技能·涩涩 里把对应项改为 1。
   - **时间/日期**：时间·日期 → 时 / 分 / 经过天数。
   - **物品/书籍**：书本·道具、饮品 里的数量项。

## 自行扩充（新增未收录变量）

1. 打开 `变量地址对照表.csv`，按名称找到目标变量的 `var_id` 与 `offset_hex`。
2. 在 CE 里手动添加地址：`Address` 填 `"Game.exe"+00DAD67C`，`Offsets` 填 `offset_hex` 与 `0` 两项，类型 4 Bytes。
3. 存盘即可固化到表内。

## 注意事项

- 仅修改「通常变量」数值；**不建议**改引擎状态（地图/BGM/解释器）类内存，容易崩溃。
- 修改前建议先手动存档一份；改属性上限类（最大行动力/最大精力）时注意与当前值匹配。
- 表中偏移均已按 `var_id×4` 机械推导，并与原 `Ver3.CT` 的 29 个已知条目逐一核对一致；其余条目随变量名一并来自游戏数据库 `SysDatabase.json`，非猜测。
- 本目录文件仅为游戏修改用途；请支持正版。
