## 1. 二进制布局

### 1.1 通用指令头（与 @@BT@@docs/FORMAT_SPEC.md@@BT@@ §3 一致）

~~~
u8   param_count      ; = 整型参数个数 + 1（含 command id 自身）
u32  command_type     ; 250
s32  int_args[param_count - 1]
u8   branch_depth     ; 缩进层
u8   string_count
str  strings[string_count]   ; str = u32 长度(含结尾 NUL) + 载荷
u8   have_route       ; 250 恒为 0
~~~

250 的实测形状【已验证】：

| 项 | 值 |
|---|---|
| param_count | 6（argc==5，2,647 条）/ 5（argc==4，16 条） |
| string_count | 4（2,658 条）/ 0（5 条） |
| have_route | 0（全部 2,663 条） |

在 @@BT@@work/full/BasicData/CommonEvent.dat@@BT@@（5,532,175 字节）偏移 **0x0002657C** 处，公共事件

### 1.3 argc == 4 的 16 条【已验证】

argc==4 时**没有 arg4**，要写入的字符串放在 stringArgs[0]。这 16 条的 flags 只取
@@BT@@{0x0002, 0x10002, 0x10012, 0x50002}@@BT@@ —— **全部带 bit1(0x2)**。

~~~

CE74  pc185  [21,90,1,65554]        flags=0x10012  "\\cself[9] を習得！\\r\\n"
CE86  pc155  [19,1600022,5,327682]  flags=0x50002  "------"   -> 付与文字列[後]
CE86  pc181  [19,1600022,9,327682]  flags=0x50002  "------"   -> [オプション]予備文字列A
CE110 pc29/pc103/pc163 [19,1600032,4,327682] "->"            -> 付与文字列[前]
CE112 pc195  [19,1600032,4,327682]  flags=0x50002  "->"       -> 付与文字列[前]
CE112 pc205  [19,1600032,0,327682]  flags=0x50002  "<装備を外す>" -> 項目文
CE112 pc206  [19,1600032,0,327682]  flags=0x50002  "->"       -> 説明文
CE153 pc29/pc104/pc165 [19,1600032,4,327682] "->"
CE192 pc187  [19,0,6,327682]        flags=0x50002  "何も行動せずターンを進めます" -> 説明文

## 2. 参数语义总表

| 参数 | 读（bit12=1） | 写（bit12=0） | 运行时是否需要求值 |
|---|---|---|---|
| arg0 | DB 类型号 | DB 类型号 | **需要**（>=1600000 时是自身变量，实测 @@BT@@[1600090,1600010,29,0x41200,...]@@BT@@） |
| arg1 | 行 / 记录号 | 行 / 记录号 | **需要**（实测 @@BT@@[19,SV32,0,0x50000,...]@@BT@@、@@BT@@[21,SV0,0,0x50000,...]@@BT@@） |
| arg2 | 列 / 项目号 | 列 / 项目号 | **需要**（实测 @@BT@@[2,SV0,SV28,0x10020,...]@@BT@@） |
| arg3 | 位域（常量） | 位域（常量） | 不需要 |
| arg4 | 目标变量（必须可写） | 源值（字面量 / 变量 / 字符串变量） | **需要** |

【已验证】bit12=1 的 1,781 条里 arg4 **从来不是字面量**（self 1,755 / strvar 23 / var 3）；
bit12=0 的 882 条里字面量 279、负数 23、strvar 21、self 543、无 arg4 16。
—— 「读的目标必须是变量、写的源可以是常量」这条统计本身就独立证明了 bit12 的方向语义。

### 2.1 arg2 的哨兵值【已实测】

| 值 | 含义 | 证据 |
|---|---|---|
| -1 / -2 / -3 | 「当前行 / 循环当前项 / 最后一项」之类的引擎哨兵 | CE267 @@BT@@[24,-1,0,0x11100,SV20]@@BT@@、CE267 @@BT@@[24,1600021,-3,0x11100,SV7]@@BT@@ |

实现建议：负行号夹到 0；负列号夹到 0 或「字段数 - 1」。本作两条哨兵指令都落在
@@BT@@顔グラフィック名@@BT@@（SysDatabase#24，12 行 1 字段）上，夹到 0 即正确。
