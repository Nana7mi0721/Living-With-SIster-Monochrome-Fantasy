## 6. 实现伪代码（Rust）

### 6.1 分派骨架

全部 sub 共享「求一个值 → 写进 dst → pc+1」，差别只在取值函数。注意返回值用 `Option<i64>`：
`None` 表示「不写变量」（对应官方「存在しないイベントIDの場合は何も起きない」）。

```
// crates/wolf-vm/src/exec.rs  —— opcode 124
let dst  = cmd.args[0];
let sub  = cmd.args[1];
let val: Option<i64> = match sub {
    0x3000 => {                       // argc == 3
        let field = cmd.args[2];
        other_get(vm, field)
    }
    0x1000 | 0x1200 => {              // argc == 4
        let obj   = vm.eval_num(cmd.args[2]);   // 角色ID：可能是负哨兵，也可能是变量
        let field = cmd.args[3];
        char_get(vm, obj, field, /*zoom=*/ sub == 0x1200)
    }
    0x4000 | 0x4400 => {              // argc == 4
        let pic   = vm.eval_num(cmd.args[2]);   // 图片番号：可能是变量，到 5 位数
        let field = cmd.args[3];
        pic_get(vm, pic, field, /*no_effect=*/ sub == 0x4400)
    }
    _ => {                            // 0x2000 等本作 0 次的 sub
        tracing::warn!("124: sub {sub:#06x} not implemented; variable kept");
        return Ok(());                // 不动变量
    }
};
if let Some(v) = val {
    vm.store_num(dst, v);             // 与 121 的「=」完全同一条写入路径，不钳制
}
vm.pc += 1;
```

### 6.2 `other_get`（0x3000）

```
fn other_get(vm: &mut Vm, field: i64) -> Option<i64> {
    Some(match field {
        0  => vm.map.current_id() as i64,                       // 現在のマップ番号
        1  => vm.audio.current_bgm_id(),                        // 再生中BGM番号（無ければ -1）
        7  => vm.input.mouse_left_state(),                      // 0/1/2
        8  => vm.input.mouse_right_state(),
        9  => vm.input.mouse_middle_state(),
        10 => vm.input.wheel_delta(),                           // ±
        11 => vm.input.event_id_at_mouse(vm),                   // 無ければ -1
        12 => vm.input.event_id_at_mouse_ext(vm),               // 無ければ -1
        18 => vm.interp.running_trigger_event_number(),         // コモンなら +500000，無ければ -1
        20 => vm.input.mouse_x(),                               // 画面px
        21 => vm.input.mouse_y(),
        17 => 0,          // 未定（§9.1），先返回 0 并留日志
        _  => { tracing::debug!("124/0x3000 field {field} unused in this game"); 0 }
    })
}
```

`mouse_*_state()` 的三态必须是：**本帧按下=2 / 按住=1 / 未按=0**（官方原文），
不能只给 bool —— 本作 `111 …== 2` 判断「刚按下」的地方到处都是（ev225 pc55 等），
若恒返回 1 会导致「按住不放会重复触发」或「永远不触发」。

`field 18` 的实现要点：维护一个「当前正在执行的非并行事件编号」栈；
并行协程（run_condition 2/3）查它时若栈空返回 -1；公共事件要 `+500000`
（本作 `111 self10 == 500065` ⇒ 公共事件 65）。
