
## 2. 页面激活规则：「最高活动页」

### 2.1 算法（«BT»crates/wolf-format/src/mps.rs«BT» 的 «BT»MapEvent::active_page_index«BT»）**已验证**

«BT»«BT»«BT»
active_page(ev, get_var):
    for page in reverse(ev.pages):           # 从最后一页往前扫
        if page.conditions_met(get_var):     # 4 个槽全部成立（未启用的槽恒成立）
            return page                      # 第一条命中即胜出
    return None                              # 所有页都不成立 => 事件不出现
«BT»«BT»«BT»

两条必须记住的推论：**(1)** 页码大 = 优先级高，所以「例外 / 覆盖」页写在后面；
**(2)** 没有启用槽的页（«BT»raw_sw == [0x20,0x20,0x20,0x20]«BT» 之类）恒成立，是「无条件兜底页」，
放在最后就永远赢、放在前面只在更高页都不成立时赢。

### 2.2 条件槽编码 **已验证**

每页 4 个槽，槽 «BT»i«BT» 的原始字节 «BT»trigger_switches[i]«BT»：

| 位 | 含义 |
| :--- | :--- |
| 低 4 位 | «BT»1«BT» = 该槽启用；«BT»0«BT» = 停用（**停用槽里的变量号与阈值是陈旧残留，不可使用**） |
| 高 4 位 | 运算符：«BT»0 >«BT» / «BT»1 >=«BT» / «BT»2 ==«BT» / «BT»3 <=«BT» / «BT»4 <«BT» / «BT»5 !=«BT» / «BT»6 按位与 |
| 配套数组 | «BT»trigger_variables[4]«BT»（u32 魔法变量号）、«BT»trigger_values[4]«BT»（s32 阈值） |

变量号沿用魔法寻址：«BT»1000000+n«BT» = Ev Self 自变量 n，«BT»2000000+n«BT» = 通常变量 n，«BT»9000000+n«BT» = 系统变量。

### 2.4 优先级分析：没有一页是「永远赢不了」的 **已验证**

对每个多页事件穷举「能让任一条件改变真值」的赋值组合（§4.1 的断点域），统计每页在多少组合里胜出：

| 地图 | 多页事件 | 穷举组合数 | 可胜页 | 低页在高页同时成立时必输的对数 |
| :--- | --: | --: | :--- | --: |
| «BT»SampleMapA.mps«BT» | 18 | 354 225 | 全部（0 死页） | 43 |
| «BT»SampleMapA_1.mps«BT» | 4 | 78 | 全部（0 死页） | 2 |
| 其余 7 张 | 0（全单页） | — | 全部 | 0 |

「低页在高页同时成立时必输」是**规则本身**（高页优先），不是缺陷；有意义的是「可胜页 = 全部」，
即没有任何一页在枚举域里不可达。逐事件的胜出计数见 §8 每张图后面的优先级小节。
